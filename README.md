# Company Slots

More company vehicle slots and higher spawn caps.

More company vehicle slots and higher spawn caps.

Settings: `Binaries\Win64\company_slots.ini`.

## Install

Needs [Plugin Loader](https://github.com/qxZap/mt-plugin-loader) (`version.dll`) in
`MotorTown\Binaries\Win64\`. Put `mt_plugin_CompanySlots.dll` in `MotorTown\Binaries\Win64\plugins\`.

## Build

`build.bat` (MSVC 2022, x64) writes `out\mt_plugin_CompanySlots.dll`.
