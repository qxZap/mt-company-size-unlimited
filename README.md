# Company Size Unlimited

More company vehicle slots and higher spawn caps.

Lifts the 20 company vehicle limit: buy more slots, and the counter, the save load and vehicle ids all follow.

Settings: `Binaries\Win64\plugins\company_size_unlimited.ini`.

Do not load a save with more than 20 company vehicles without this plugin. On someone else's server, that server's limits apply.

## Install

Needs [Plugin Loader](https://github.com/qxZap/mt-plugin-loader) (`version.dll`) in
`MotorTown\Binaries\Win64\`. Put `mt_plugin_CompanySizeUnlimited.dll` in `MotorTown\Binaries\Win64\plugins\`.

## Build

`build.bat` (MSVC 2022, x64) writes `out\mt_plugin_CompanySizeUnlimited.dll`.
